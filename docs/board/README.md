Operator hat es am 04.10.2026 abgesegnet („ja bild passt“, #617 Zeile 1):
Variante Kombi/S0 — die einfache Karte von heute (3a: Frage, Beispiel, Bild,
Ja, Nein, Notiz, Rückgängig), der Verlauf entschiedener Zeilen, der Zustand
„Zugang fehlt“, die Filterleiste und die Telefon-Variante. Veröffentlicht als
Artifact: https://claude.ai/artifact/14bpW7FnK7sEPvSLNFdtyT.

Vision und die dort festgelegten Entscheidungen stehen in Item #617. Das Bild
ist Prinzip, nicht Pixelvorgabe: eine Änderung, die die Oberfläche des Boards
erweitert, zeichnet zuerst ein eigenes Detailbild als Erweiterung dieses
Bildes — zum Beispiel die Später-Ablage (#617 Zeile 5) und die Live-Nutzung
hinter Webauth (#617 Zeile 6).

Das Mockup ist eine statische Seite mit Beispieldaten. Es spricht nicht mit

Eine Änderung an der Oberfläche des Boards beginnt hier: zuerst dieses Mockup
ändern und vom Operator absegnen lassen, dann bauen.
